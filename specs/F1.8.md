# Spec F1.8 — Irisan vertikal ujung ke ujung (`vir smoke`)

## Tujuan

Membuktikan semua lapisan menyatu dalam satu perintah: BPE → VQ-VAE multiscale →
generator → decoder → sampling, dilatih mini di CPU, lalu gerbang **G1** (PRD §2.4
dan F1.8) ditegakkan oleh CI.

Gerbang G1 (PRD F1.8):

1. **Rekonstruksi membaik per level** — akurasi rekonstruksi kumulatif `recon_k`
   tidak menurun saat `k` naik.
2. **Loss turun jelas** — `loss_after < MIN_DROP · loss_before` (kepala/gen).
3. **Memoriasi 8 sampel, reproduksi persis** — model menghafal 8 sampel dan
   men-generate ulang **identik** (`exact_match = true`).
4. **Σℓ_k sesuai F1.1** — `recon_fraction = Σℓ_k / (K·L)` harus sama dengan jadwal
   `ℓ_k` yang dihitung `vir-common` (F1.1), bukan angka yang dikonstanta.

Pipeline mini: `configs/mini.yaml` (K kecil 4–6, L = 32–64, d/hidden kecil) sehingga
seluruh latihan selesai dalam hitungan menit di CPU. Lihat PRD F1.8.

## Trait antarmuka

### 1. Fungsi inti (Rust)

```rust
// Krate orkestrator (vir-model / bind-eng) — diisi model-eng & bind-eng.
pub struct SmokeConfig {
    pub seed: u64,
    pub num_levels: usize,   // K
    pub target_length: usize, // L
    pub samples: usize,      // 8 (memoriasi)
    // ... field lain dari configs/mini.yaml
}

pub struct SmokeReport {
    pub status: String,               // "ok" | "fail"
    pub build: Option<String>,        // info build (versi/target/profil)
    pub levels: Vec<LevelStat>,       // statistik per level, terurut k naik
    pub recon_fraction: Option<f64>,  // Σℓ_k / (K·L)
    pub loss_before: Option<f64>,
    pub loss_after: Option<f64>,
    pub exact_match: Option<bool>,    // reproduksi 8 sampel persis
    pub roundtrip_ok: Option<bool>,   // tokenizer roundtrip (kompat lama)
}

pub struct LevelStat { pub k: usize, pub ell: usize, pub recon: f64, pub loss: f64 }

/// Jalankan irisan vertikal mini; `Err` bila gerbang G1 gagal.
pub fn run_smoke(cfg: &SmokeConfig) -> Result<SmokeReport, vir_common::VirError>;
```

### 2. CLI dan Python (bind-eng)

- `vir smoke --json` → cetak satu objek JSON `SmokeReport` ke stdout. Keluar dengan
  kode ≠ 0 bila `status == "fail"` (tanpa `|| true` di CI, lihat `smoke.yml`).
- `vir.smoke()` (Python) → kembalikan `dict` dengan skema sama.

### 3. Skema JSON (divalidasi `vir-e2e::validate_smoke_json`)

```json
{
  "status": "ok",
  "build": "VIR Vbeta (rust, target=x86_64, profile=release)",
  "roundtrip_ok": true,
  "levels": [
    {"k": 1, "ell": 2, "recon": 0.10, "loss": 1.00},
    {"k": 2, "ell": 4, "recon": 0.55, "loss": 0.40}
  ],
  "recon_fraction": 0.75,
  "loss_before": 2.0,
  "loss_after": 0.4,
  "exact_match": true
}
```

- `status` wajib ada dan bernilai `"ok"`/`"fail"`.
- Field lain **opsional** agar kompatibel dengan keluaran tokenizer lama; validator
  menegakkan tipe bila field ada.
- `vir-e2e::SmokeReport::gate_g1_ok()` menegakkan kriteria G1 di atas (hanya field
  yang tersedia).

### 4. Kontrak CI

- `ci.yml` job `e2e` menjalankan `tests/e2e` (membangun `vir-cli` lebih dulu) dan
  `nextest --workspace` (tanpa `--no-tests=pass`).
- `smoke.yml` menjalankan `vir smoke --json` **tanpa** `|| true`;CI gagal bila
  pipeline G1 tidak lulus.

## Kriteria tes

1. `tests/e2e/tests/smoke_cli.rs::smoke_json_matches_schema_and_gate` — menjalankan
   `vir smoke --json` nyata, memvalidasi skema, dan memanggil `gate_g1_ok()`.
2. Unit tes `vir-e2e` (`src/lib.rs`): skema lama & penuh valid; JSON rusak/`status`
   hilang ditolak; `exact_match=false`, `loss` naik, dan rekonstruksi menurun
   **menggagalkan** gerbang.
3. Unit tes `vir-eval` (`tests/eval_tests.rs`) — estimator & metrik yang dipakai
   laporan (pass@k, rekonstruksi) benar.
4. Gerbang G1 (PRD F1.8): `recon` tidak menurun antar level; `loss_after <
   MIN_DROP·loss_before`; `exact_match == true`; `recon_fraction` cocok dengan
   `vir-common::level_schedule` (F1.1) untuk `K`, `L` di `configs/mini.yaml`.
5. Determinisme: seed sama → keluaran `vir smoke` identik (byte-for-byte pada field
   numerik).

## Bukti

- Tautan run CI `ci` (job `nextest`, `forbid_stubs`, `e2e`) dan `smoke` yang hijau.
- Artefak kurva loss + metrik per level yang diunggah `smoke.yml` (F0.5).
- ADR kuantizer (residual FSQ vs VQ-EMA) dan snapshot TUI (F1.10) — bagian G1.
- IP: alamat run terisi setelah push (`gh run list`).
