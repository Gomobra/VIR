# Spec F3.8

## Tujuan
Lihat PRD.md bagian F3.8: satu aplikasi TUI (dasbor, latih, generate, memori,
RLM, eval, log, setelan) dengan arsitektur Model–Update–View, palet perintah,
overlay bantuan, tata letak responsif, dan tema.

## Trait antarmuka
- `App` (model) + `Msg { Tick, Key(KeyEvent), Command(String), Resize(u16,u16) }`
  + `App::update` murni; efek samping hanya lewat state (`Cmd` menyusul).
- `Screen { Dashboard, Train, Generate, Memory, Rlm, Eval, Logs, Settings }`
  dengan `titles()`, `index()`, `from_index()`.
- `layout::LayoutMode::from_width(u16) -> {Compact <60, Medium 60..=100, Wide >100}`
  dan `layout::body(area, mode, left, right)`.
- `theme::{ThemeName, ColorMode, Palette, no_color, mode_for, resolve_mode}`:
  palet gelap/terang/kontras tinggi/buta warna, cadangan 256, `NO_COLOR`.
- `keymap::{HELP, COMMANDS, command_label}` + `palette::{PaletteState, fuzzy_score}`.

## Kriteria tes
- Snapshot render tiap layar pada 3 ukuran (40×20, 80×24, 120×40) — `tests/render.rs`.
- Fuzz input acak (tombol + resize) tanpa panik dan invarian model terjaga —
  `tests/input_fuzz.rs` (`proptest`).
- Responsif: ambang <60 / 60–100 / >100, panel menumpuk vs berdampingan —
  `tests/layout.rs`.
- Tema/`NO_COLOR`: palet valid, `NO_COLOR` menang atas setelan — `tests/theme.rs`
  dan PTY `tests/pty.rs::pty_no_color_mematikan_warna_truecolor`.
- State murni: tab, palet perintah, toast, filter log, setelan, memori, RLM —
  `tests/app.rs`.
- PTY: mulai → render → keluar dengan status 0; tanpa tty keluar cepat dengan
  pesan galat — `tests/pty.rs`.
- Anggaran render per frame diuji — `tests/render_budget.rs`.
