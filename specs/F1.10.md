# Spec F1.10

## Tujuan
Lihat PRD.md bagian F1.10: dasbor latihan `vir tui` yang membaca metrik JSONL
secara langsung (status run, backend, gerbang, run terbaru) dan dipakai untuk
memantau G1/G2. Layar lain (F3.8) dibangun di atas fondasi yang sama.

## Trait antarmuka
- `vir_tui::run()` / `run_with_paths(AppPaths)` — loop Elm: `draw` → `poll` →
  `App::update(Msg)`; keluar bersih saat `q`.
- `App::update(&mut self, Msg) -> ()` murni (tanpa efek samping di luar state).
- `AppPaths` — metrics/logs/eval/rlm/generate/memory/settings (bisa ditimpa env
  `VIR_METRICS`, `VIR_LOG`, `VIR_EVAL`, `VIR_RLM_EVENTS`, `VIR_GENERATE_EVENTS`,
  `VIR_MFS_PATH`).
- `MetricsReader::poll/snapshot` — tail JSONL + pindai direktori checkpoint.
- `screens::render(&mut Frame, &App)` — satu pintu render semua layar.

## Kriteria tes
- `crates/vir-tui/tests/render.rs`: dasbor dirender ke `TestBackend` pada 40×20,
  80×24, 120×40; tidak panik, ukuran baris cocok, panel `Status run` tampil.
- `crates/vir-tui/tests/app.rs`: `update` untuk tab, jeda, checkpoint, resize.
- `crates/vir-tui/tests/render_budget.rs`: render satu frame ≤ anggaran (33 ms,
  pagar CI 150 ms).
