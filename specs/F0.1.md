# Spec F0.1 — Workspace Rust dan wheel Python

## Tujuan
Workspace Cargo membangun wheel dari CI; `import vir` berjalan.

## Trait antarmuka
- `vir_common::build_info() -> String`
- `vir_common::ModelConfig` (serde, validate)
- `vir_py::_core` mengekspor `build_info`, `version`

## Kriteria tes
- `cargo build --workspace` lulus.
- `cargo test --workspace` lulus.
- Wheel maturin terbangun (CI manylinux x86_64).
- `python -c "import vir; print(vir.build_info())"` lulus.

## Bukti
- Run CI hijau.
